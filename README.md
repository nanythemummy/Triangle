# Photogrammetry Triangle #
Code and Model by Kea Johnston, Postdoctoral Scholar at ISAC at the University of Chicago, and Chicago's Field Museum

The photogrammetry triangle is a tool for automating the scaling and orientation of a model built in Agisoft Metashape Pro. 
It can also be a useful part of the photography process.

In this folder project is an STL for printing your own triangle-shaped photogrammetry scale. The triangle has three computer readable targets on it
which can be used to set scale and orientation in Agisoft Metashape Pro.
From Agisoft Metashape Pro, you can run the script "Metashape_OrientOnMarkers.py" in the scripts subdirectory. If you use the triangle in the models directory in
your model, the script will detect the markers, set the scale, and rotate the object such that it is rightside up.

## Printing your own Triangle ##
* Print out the file "Model/Triangle.stl" in the color of your choice.
* Print out the file "targets.stl" in white matte filament, and "target_interior.stl" in black filament.
* Note the order of the stl files on the plate--they are arranged in a triangle and go in the corresponding points on the triangle. See the below digram. if you get the order wrong, you will have to reconfigure the script to reflect the new order.
![A 45/45/90 triangle with computer readable targets. They read clockwise, 1, 2, 3](/ReadmePictures/ModelOrientation.png)

* When printed, assemble the triangle by gluing the black inserts into the corresponding white targets, and gluing the white targets onto the triangle base. 
* Measure the length between the centers of the target on each leg of the triangle in m,cm, or mm (this doesn't support inches) and write it down.
* If the triangle is too big for your purposes, I've included the original blender files for it so you can resize it to be whatever size you want. 
  * I recommend leaving the targets alone since it will be hard to get the inserts to fit in them if you scale them too much. Just use the boolean operator to cut new emplacements for your targets in the smaller triangle. 
* If you don't have a 3d printer, you can also just print out the markers in model/markers.pdf (these are generated by metashape itself) and tape them to a set-square.

## Photogrammetry with the Photogrammetry Triangle ##
* If you are doing photogrammetry in the field, throw the triangle down on a flat surface facing whatever direction you think ought to be "up" in the final model.
  * Photograph as normal, making sure that the targets are shot obliquely in at least three pictures--it has a harder time detecting them from an angle. 
  * If you want the x axis to be north, you can orient it
  such that the leg with markers 2-3 is oriented parallel to your north arrow with 2 in the south and 3 in the north.
* If you are photographing something large where you are moving around the object as opposed to moving it, you can do the same.
  * Put the triangle on a flat table next to the object and proceed to photograph.
* If you are photographing on a turntable, you should put the triangle on the turntable with your object. 
  * You can put one leg parallel to your object and use the other
  other leg as a sort of watch-hand to give you an idea of how many degrees have rotated since the last picture you took.
  * If you have to turn the object upside down to get the other
  side, take the triangle off the turntable before you turn it upside down to allow Metashape to merge the two models without getting confused by the same object in both sets
  of pictures!

## Detecting the Markers and Orienting your Model ##
* If you made any changes to the size of the Photogrammetry Triangle when you were printing it out, or you glued the targets in the wrong order, you will want to change the configuration. 
  * Use a text editor to open the file /Scripts/Metashape_OrientOnMarkers.py and navigate to the following: 
  ``` TRIANGLE = {
    "type":"12bit",
    "unit":"mm",
    "scalebars":{
        "type":"explicit",
        "bars":[
        {
        "points":[1,2],
        "distance":180,
        "units":"mm"
        },
        {
        "points":[2,3],
        "distance":179,
        "units":"mm"
        },
        {
        "points":[1,3],
        "distance":254,
        "units":"mm"
        }
        ],
        "axes":{
                "xpos":[2,3],
                "xneg":[],
                "zpos":[2,1],
                "zneg":[]
            }
    }
  }
  ```
    * Enter the distance in mm between the  points listed under "distance" for each leg. For example, on the default model the leg 1-2 is 18 cm long, or 180 mm. If you change to centimeters, change the units to "cm". You can see the leg in the "points" fields so, the first leg in the list is [1,2], or target 1 to target 2.
    * If you glued the targets wrong, make sure that the distances are corrects for the legs that you created, keeping in mind the way the markers look in the above picture.
    * You can also define axes here. For example, the positive direction on the x axis is represented as an arrow or vector from point 2 to point 3. This configuration format was initially designed for a system that had more than 3 markers where the object needed to be positioned in the middle--that's why there's a different place for the negative x axis.
    * If you are adventurous and have used a different type of marker on your triangle, you can specify that under "type." You should not have to do this unless you. make your own CUSTOM triangle, but if you do, your options are "Circular","12bit","14bit","16bit","20bit","Cross"
* Inside Agisoft Metashape Pro (you cannot run scripts in the Standard Verion), load your photos and align them as normal. 
* Then, click on the menu "Tools->Run Script"
* Navigate to the folder Scripts/Metashape_OrientOnMarkers.py and click "OK".
* You should have a "Scripts" menu at the top now. 
* Click on the "Scripts->Detect Orientation Triangle"
  * Note that your markers should appear onscreen with scale lines around them. If your model "disappears", click the button with the box and four arrows around it in the toolbar at the top of the screen.
